import { Card, CardGrid } from '@astrojs/starlight/components'

```sh
npm i -g @repobuddy/upx

upx semver@^7 --coerce v1.2
```

<CardGrid>
	<Card title="Local-first" icon="rocket">
		Walks `node_modules` from the current directory upward, then the global root. The nearest install
		satisfying the range wins, and `upx` spawns its binary directly.
	</Card>
	<Card title="Ranges, not pins" icon="approve-check">
		Matching `^1` rather than `1.2.3` is the point — one global install serves every caller on that
		major.
	</Card>
	<Card title="Transparent" icon="seti:powershell">
		The child owns stdout, stderr, and the exit code. `upx` never wraps or reformats output, and
		installs nothing.
	</Card>
	<Card title="Honest about cost" icon="warning">
		It is a latency fix, not a correctness fix. The [tradeoffs](./concepts/tradeoffs/) are documented
		as carefully as the wins.
	</Card>
</CardGrid>
